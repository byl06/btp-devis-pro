# 📖 Guide Utilisateur — BTP Devis Pro

Bienvenue sur **BTP Devis Pro** ! Ce guide vous aide à prendre en main l'application rapidement.

---

## 🔑 1. Connexion / Inscription

### Créer un compte
1. Aller sur [btp-devis-pro-1.onrender.com/register.html](https://btp-devis-pro-1.onrender.com/register.html)
2. Remplir le formulaire
3. Valider → Un essai gratuit de **14 jours** est automatiquement activé

### Se connecter
1. Aller sur [btp-devis-pro-1.onrender.com/login.html](https://btp-devis-pro-1.onrender.com/login.html)
2. Saisir email + mot de passe
3. Cliquer sur "Se connecter"

---

## 👥 2. Gestion des clients

### Ajouter un client
1. Menu → **Clients**
2. Cliquer sur **"Ajouter"**
3. Remplir : Nom, Téléphone, Email, Adresse, IFU (optionnel)
4. Enregistrer

### Modifier un client
1. Clients → Carte du client
2. Cliquer sur l'icône **✏️ Modifier**
3. Modifier les informations
4. Enregistrer

### Supprimer un client
1. Clients → Carte du client
2. Cliquer sur **🗑️ Supprimer**
3. Confirmer

---

## 🏗️ 3. Gestion des projets

### Ajouter un projet
1. Menu → **Projets**
2. Cliquer sur **"Nouveau projet"**
3. Remplir : Nom, Description, Localisation, Statut, Dates, Progression
4. Enregistrer

### Suivre un chantier
- La **progression** s'affiche en % avec une barre colorée
- Le **statut** : En attente / En cours / Terminé
- Les **dates** : Début et fin prévues

---

## 📄 4. Gestion des devis

### Créer un devis
1. Menu → **Devis**
2. Cliquer sur **"Nouveau devis"**
3. Sélectionner **Client** et **Projet**
4. Ajouter des articles : Désignation, Quantité, Prix unitaire
5. Cliquer sur **"Créer le devis"**

### Valider un devis
1. Devis → Cliquer sur **👁️ Voir**
2. Vérifier les informations
3. Cliquer sur **"Valider le devis"**
4. ⚠️ Une fois validé, le devis ne peut plus être modifié

### Télécharger un devis en PDF
1. Devis → Cliquer sur **👁️ Voir**
2. Cliquer sur **"Télécharger PDF"**

### Modifier un devis
1. Devis → Cliquer sur **✏️ Modifier** (seulement si non validé)
2. Modifier les informations
3. Enregistrer

### Supprimer un devis
1. Devis → Cliquer sur **🗑️ Supprimer** (seulement si non validé)
2. Confirmer

---

## 💰 5. Acomptes et situations de travaux

### Configurer l'acompte
1. Devis → **👁️ Voir**
2. Cliquer sur **"Configurer l'acompte"**
3. Saisir le pourcentage (ex: 20%)
4. Valider → Le montant est calculé automatiquement

### Marquer l'acompte comme payé
1. Devis → **👁️ Voir**
2. Cliquer sur **"Marquer payé"** (à côté du badge acompte)
3. Confirmer

### Ajouter une situation de travaux
1. Devis → **👁️ Voir**
2. Cliquer sur **"Ajouter une situation"**
3. Saisir le pourcentage (ex: 30%)
4. Décrire les travaux réalisés
5. Valider

### Marquer une situation comme payée
1. Devis → **👁️ Voir**
2. Dans le tableau "Situations", cliquer sur **💳 Marquer payée**
3. Confirmer

---

## 📊 6. Facturation

### Générer une facture simple
1. Devis → **👁️ Voir** (uniquement pour un devis validé)
2. Cliquer sur **"Générer facture"**
3. La facture apparaît dans l'onglet **Factures → Simples**

### Normaliser une facture (e-MCF)
1. Factures → **Simples**
2. Cliquer sur **"Normaliser"** (icône document)
3. Saisir l'**IFU du client** (13 caractères)
4. Saisir la **méthode de paiement** (ESPECES, VIREMENT, etc.)
5. Valider → La facture devient normalisée avec QR Code

### Télécharger une facture
- **Facture simple** : PDF classique
- **Facture normalisée** : PDF avec QR Code, NIM, Code MECeF

### Marquer une facture comme payée
1. Factures → Simples ou Normalisées
2. Cliquer sur **💳 Marquer payée**
3. Confirmer

---

## 📦 7. Archivage

### Archiver une facture
1. Factures → Simples ou Normalisées
2. Cliquer sur **📦 Archiver**
3. Confirmer → La facture disparaît de la liste active

### Voir les archives
1. Factures → Onglet **Archives**
2. Deux sous-onglets : **Simples archivées** / **Normalisées archivées**

### Restaurer une facture
1. Factures → Archives
2. Cliquer sur **↪️ Restaurer**
3. La facture revient dans la liste active

---

## ⚙️ 8. Paramètres

### Informations de l'entreprise
1. Menu → **Paramètres** → **Entreprise**
2. Remplir : Nom, Email, Téléphone, Adresse, Slogan, Site web
3. Enregistrer

### Logo
1. Paramètres → Entreprise
2. Télécharger une image (PNG, JPG)
3. Valider

### En-tête personnalisé (image)
1. Paramètres → Entreprise → "Importer votre en-tête"
2. Télécharger une image (PNG, JPG, WEBP)
3. L'en-tête apparaît sur les devis et factures

### Couleurs
1. Paramètres → Entreprise → "Couleurs personnalisées"
2. Choisir : Primaire, Secondaire, Accent
3. Appliquer

### Fiscal (NIF)
1. Paramètres → Fiscal
2. Remplir : NIF (13 caractères), Régime TVA, etc.
3. ⚠️ Le NIF est **obligatoire** pour les factures normalisées

### Espace Abonnement
1. Paramètres → Espace Abonnement
2. Voir votre offre actuelle, jours restants, progression
3. Contacter l'administrateur pour changer d'offre

### Sécurité
1. Paramètres → Sécurité
2. Changer de mot de passe (ancien + nouveau)
3. Se déconnecter

### Sauvegarde
1. Paramètres → Sauvegarde
2. **Télécharger sauvegarde** : Export JSON de toutes vos données
3. **Restaurer sauvegarde** : Importer un fichier JSON

## ❓ 11. Questions fréquentes (FAQ)

### Comment obtenir un essai gratuit ?
L'essai gratuit de 14 jours est **automatiquement activé** lors de l'inscription.

### Que faire si j'oublie mon mot de passe ?
Cliquer sur **"Mot de passe oublié ?"** sur la page de connexion. Un message est envoyé à l'administrateur via WhatsApp.

### Pourquoi je ne peux pas créer de nouveau client ?
Vérifiez votre abonnement. Si vous êtes en offre Artisan (5 clients max), vous avez atteint la limite.

### Qu'est-ce que la facture normalisée ?
Une facture conforme à la réglementation de la DGI, avec :
- NIM (Numéro d'Identification)
- QR Code
- Code MECeF
- Date et heure fiscales

### Où trouver mon NIF ?
Le NIF est configuré dans **Paramètres → Fiscal**.

### Comment changer d'offre ?
Aller dans **Paramètres → Espace Abonnement** et contacter l'admin via le bouton "Contacter".
